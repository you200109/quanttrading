## 报告漏洞

如果您发现安全漏洞，请**不要**在公开 Issue 中报告。

请发送邮件至项目维护者，或使用 GitHub 的[私密漏洞报告](https://github.com/you200109/-/security/advisories/new)功能。

我们将在 48 小时内确认收到报告，并在 7 天内提供修复方案。

## 安全最佳实践

- 所有 API 凭证通过环境变量注入，不硬编码
- 交易默认模拟盘模式
- 定期依赖安全审查（Dependabot + CodeQL）
- 凭据扫描防止密钥泄露（Gitleaks）
