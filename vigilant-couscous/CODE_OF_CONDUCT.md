# 行为准则

## 我们的承诺

为了营造一个开放和友好的社区环境，我们承诺尊重所有参与者。

## 我们的标准

**鼓励的行为：**
- 使用友好和包容的语言
- 尊重不同的观点和经验
- 优雅地接受建设性批评
- 关注对社区最有利的事情
- 对其他社区成员表示同理心

**不可接受的行为：**
- 使用性暗示的语言或图像
- 挑衅、侮辱或贬低性评论
- 公开或私下骚扰
- 未经明确许可发布他人私人信息
- 其他在专业环境中被认为不适当的行为

## 执行

项目维护者有责任澄清可接受行为的标准，并对任何不可接受行为采取适当和公平的纠正措施。

违反行为准则的参与者可能会被暂时或永久禁止参与本项目。

## 报告

如遇到骚扰或其他不可接受的行为，请通过 GitHub Issues 联系项目维护者。
